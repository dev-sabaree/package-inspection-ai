# Package Inspection AI (YOLO)

## Dataset
The training dataset (20,000+ images) is hosted securely on Kaggle to keep the GitHub repository lightweight. 
- **Kaggle Dataset Link:** [https://www.kaggle.com/datasets/dfldfmkmkxjf/ai-cardboard]

## How to Train
1. Install requirements: `pip install ultralytics kagglehub`
2. Run training script: `python train.py`
